# Дизайн-система

Человекочитаемая карта токенов проекта: что есть в дизайне и как это называется в коде. Заполняется по макету — вручную или командой генерации из скилла `layout-developer`.

Источник: `<ссылка на макет>`.
Реализация токенов — [`core/_variables.scss`](core/_variables.scss), типографика — [`ui/_typography.scss`](ui/_typography.scss).

Тем оформления: одна. Если тем две — описать здесь обе и указать, чем переключаются (обычно атрибут `data-theme` на `<body>`, проставляемый в `header.php` по разделу сайта).

---

## Цвета

### Raw-токены

Имена один в один с переменными макета — по этой таблице сверяются с дизайнером. В стилях блоков напрямую не используются.

| Макет | CSS-переменная | HEX |
|---|---|---|
| Colors/White | `--Colors-White` | `#ffffff` |

### Семантические токены

Использовать в стилях именно их: они переключаются вместе с темой, а raw-значения — нет.

| Токен | Тема по умолчанию | Вторая тема |
|---|---|---|
| `--bg` | | |
| `--bg-surface` | | |
| `--text` | | |
| `--text-muted` | | |
| `--border` | | |
| `--accent` | | |
| `--accent-hover` | | |
| `--font-heading` | | |
| `--font-text` | | |

### Загрузка по темам

Заполнять, только если тем больше одной.

`@font-face` ленивый: браузер качает файл, только когда тема реально применяет семейство. Это работает, пока семейства задаются через `--font-heading` / `--font-text`, без хардкода в блоках.

| Страница | Грузится | НЕ грузится |
|---|---|---|
| | | |

> Не добавлять `<link rel="preload">` на эти шрифты: preload форсирует загрузку мимо темы и убивает экономию.

## Типографика

Каждый стиль — миксин в [`ui/_typography.scss`](ui/_typography.scss) плюс одноимённый класс для HTML. Блоки не набирают шрифт свойствами вручную.

Проценты `letter-spacing` из макета переводятся в `em`: 6% → `0.06em`. Цвет текста наследуется от `body`, в стилях типографики не задаётся.

### Заголовки — `--font-heading`

| Класс / тег | font-weight | size | line-height | letter-spacing | прочее |
|---|---|---|---|---|---|
| `h1` / `.h1` | | | | | |

### Текст — `--font-text`

| Класс | font-weight | size | line-height | letter-spacing | прочее |
|---|---|---|---|---|---|
| `.text-16` | | | | | |

### Кнопки, меню, ссылки — `--font-text`

| Класс | font-weight | size | line-height | letter-spacing | прочее |
|---|---|---|---|---|---|
| `.btn-16` | | | | | |

> Имена классов — пример шага именования по размеру. Реальный набор берётся из макета: сколько в нём текстовых стилей, столько здесь строк.
